# Repositório aberto — *Caminhos Discursivos Geométricos e a Geometria do Discurso*

Este é o repositório aberto do artigo **“Caminhos Discursivos Geométricose a Geometria do Discurso”**.

Ele reúne os arquivos necessários para a documentação, a transparência metodológica e a reprodutibilidade do trabalho, incluindo materiais suplementares, scripts, dados textuais e rotinas analíticas associadas ao estudo. Para replicar o estudo, é apenas necessários os arquivos "corpora.zip" e "geometrias_discursivas.py". Descompacte os arquivos .zip na mesma pasta de "geometrias_discursivas_v3.py" para rodar o script de análise.
