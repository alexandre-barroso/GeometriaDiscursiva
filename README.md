# Repositório aberto — *Geometrias Discursivas*

Este é o repositório aberto do artigo **“Geometrias Discursivas”**.

Ele reúne os arquivos necessários para a documentação, a transparência metodológica e a reprodutibilidade do trabalho, incluindo materiais suplementares, scripts, dados textuais e rotinas analíticas associadas ao estudo. Para replicar o estudo, é apenas necessários os arquivos "corpora.zip" e "geometrias_discursivas.py". Descompacte os arquivos .zip na mesma pasta de "geometria_discursiva.py" para rodar o script de análise.

Os scripts auxiliares de coleta de comentários, higienização de corpora, validação, etc, estão também compactados em arquivo .zip e disponibilizados a fim de transparência (scripts_auxiliares.zip), conjuntamente com os dados coletados antes das etapas de pré-processamento e elaboração dos corpora, no arquivo "dados_nao_processados.zip".
